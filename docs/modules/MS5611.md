# MS5611-01BA03 Barometer

## Major firmware functions

| Function | Contract |
|---|---|
| `AtlasMs5611_Init()` | Resets the device, reads all eight PROM words, rejects all-zero/all-one PROMs, and proves CRC-4. |
| `AtlasMs5611_Crc4()` | Implements the manufacturer PROM integrity algorithm as independently testable pure logic. |
| `AtlasMs5611_Compensate()` | Applies first- and second-order compensation with signed 64-bit intermediates. |
| `AtlasMs5611_Read()` | Performs bounded D2 then D1 conversion waits and returns raw plus compensated values. |

Source: [`atlas_ms5611.h`](../../App/Inc/atlas_ms5611.h) and [`atlas_ms5611.c`](../../App/Src/atlas_ms5611.c).

## Validation state

Reset/PROM command flow, valid and invalid CRC-4 cases, the manufacturer compensation example, and completed conversion accounting pass deterministic host tests; the target driver builds without warnings. The fitted device, pressure response, thermal behavior, and pneumatic installation remain bench-pending.

## RTOS access

`AtlasIO` performs D2/D1 conversions at OSR 1024 every 100 ms. The two 3 ms conversion waits yield the task while preserving exclusive I2C1 ownership. Consume `AtlasRtosSnapshot.ms5611` only with `ATLAS_RTOS_VALID_MS5611`, an `ATLAS_OK` status, and a checked timestamp. Other OSRs require a reviewed I/O-owner extension; the direct example below is for isolated pre-scheduler testing.

## Board contract

| Item | Atlas value |
|---|---|
| Fitted part | MS561101BA03-50, U14 |
| Bus | I2C1, up to 400 kHz |
| 7-bit address | `0x77` (HAL address is `0xEE`) |
| Identity evidence | Valid, nontrivial factory PROM and matching CRC-4; this part has no ID register |
| Default operation | On-demand D2 temperature followed by D1 pressure |
| OSR choices | 256, 512, 1024, 2048, 4096 |

## Startup transaction

1. Send reset command `0x1E` and wait 3 ms.
2. Read PROM words at `0xA0` through `0xAE`, in device byte order.
3. Reject an all-zero or all-`0xFFFF` image.
4. Clear the stored nibble during calculation, compute CRC-4, and compare it with PROM word 7 bits 3:0.

No valid CRC means no valid calibration coefficients; the driver remains uninitialized.

## Conversion and data contract

`AtlasMs5611_Read()` starts temperature first so the D2 value used for compensation is current, then starts pressure. Rounded-up waits are 1, 2, 3, 5, or 10 ms per conversion according to OSR. At OSR 4096 the convenience call blocks for at most approximately 20 ms plus bounded bus traffic.

The output fields are:

- `raw_pressure_d1`, `raw_temperature_d2`: unsigned 24-bit ADC values in 32-bit storage.
- `pressure_pa`: pascals. The manufacturer's 0.01 mbar result is numerically equal to Pa.
- `temperature_centi_c`: hundredths of a degree Celsius.
- `timestamp_ms`: MCU tick after both conversions and compensation.

Second-order low-temperature compensation is applied below 20 C, with the additional branch below -15 C. Pressure-to-altitude conversion is intentionally absent because it requires a chosen atmosphere/reference-pressure model.

## Typical use

```c
AtlasMs5611Sample sample;

if (AtlasMs5611_Read(&atlas_board.ms5611,
                     ATLAS_MS5611_OSR_4096,
                     &sample) == ATLAS_OK)
{
    const float pressure_hpa = (float)sample.pressure_pa / 100.0F;
    const float temperature_c = (float)sample.temperature_centi_c / 100.0F;
    /* Feed only a separately defined, tested altitude/vertical-state estimator. */
}
```

## Health and fault interpretation

| Counter | Meaning |
|---|---|
| `io_errors` | An I2C command or receive failed. |
| `prom_crc_failures` | Factory coefficient CRC did not match. |
| `invalid_prom_failures` | PROM was uniformly zero or one, a common dead-bus symptom. |
| `samples_read` | Complete compensated readings. |

## Bench acceptance

1. Decode the reset and all eight PROM reads; independently recalculate CRC from the captured words.
2. Retain a host-test run of the manufacturer example and at least boundary-vector tests around 20 C and -15 C.
3. Compare room pressure with a traceable reference and check trends under a controlled pressure change.
4. Confirm conversion times and that no new D1/D2 command starts before the previous conversion window ends.
5. Test all OSRs for plausible noise/time behavior.
6. Force NACK and corrupted PROM images; verify bounded failure and no use of coefficients after CRC failure.
7. Evaluate enclosure porting, airflow/dynamic-pressure error, moisture, light sensitivity, and thermal gradients in the actual vehicle.

## Known limits

- The driver is blocking and does not pipeline D1/D2 conversions.
- Host timestamp is after conversion, not the exact pressure sample time.
- No altitude model, sea-level reference, vent compensation, or sensor calibration record exists yet.
- PROM CRC verifies data integrity, not metrological accuracy.
