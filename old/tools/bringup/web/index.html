First installation

The existing firmware needs one initial BOOT0/NRST or SWD installation of a current bench image. After that, the Bringup image can enter DFU through USB.

Keep battery power and USB-C connected through programming. Unmount the SD card and finish pending tests first.

Recovery

If flashing verifies but the Atlas COM port does not return, disconnect USB-C and battery power. Leave BOOT0 LOW, restore battery power and USB-C, then reconnect to check the new version. A verified image does not need to be flashed again.

The factory bootloader remains available through BOOT0/NRST if a broken application cannot answer USB, or power is lost during programming.

This workflow supports Bringup and ServoBench; pyro stays inhibited in both. Normal flight-application images require a separately designed maintenance interface.
