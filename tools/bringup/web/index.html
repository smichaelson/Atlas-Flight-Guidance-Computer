First installation

The existing firmware needs one initial BOOT0/NRST or SWD installation of version 1.1.0. After that, the Bringup image can enter DFU through USB.

Keep battery power and USB-C connected through programming. Unmount the SD card and finish pending tests first.

Recovery

The factory bootloader remains available through BOOT0/NRST if a broken application cannot answer USB, or power is lost during programming.

This workflow updates the inhibited Bringup profile. Normal flight-application images require a separately designed maintenance interface.
